Save shortlist previews

Fifty Adobe Stock previews, one save each. This page tracks which are done.

The rhythm
  1. Open — the Adobe Stock page opens in a new tab.
  2. Right-click the preview image → Save image as…
  3. Copy the filename here and paste it into the save dialog. Save into assets/images/shortlist/ — your browser remembers the folder after the first one, so from then on it is only the filename.
  4. Back here, next row. Hit Re-check any time to refresh the ticks.

The extension doesn't have to be .jpg — .jpeg, .png and .webp all work. Only the Adobe ID part of the name matters, because that is what the card looks for. These stay watermarked comps until the image is licensed; a real file dropped in later under the same name takes over automatically.
